The last text a dying phone sends at 1% battery (100 characters, one message):

> Before I go: your 6am alarm is still on. I'll be dead by morning, but you'll be up at six. Worth it.

No goodbye, no low-battery pun, no charger talk. The phone's final act is petty revenge with a specific detail — the 6am alarm stays on — and the turn is that it dies happy about it. The voice is the phone's own from the first word to the last: it knows the alarm, it knows it's dying, and it thinks the trade was worth it.

## Run it

```sh
python3 main.py
```

It writes the message to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), the file the make.fun program/v1 harness grades. Deterministic: the same bytes on every run.
